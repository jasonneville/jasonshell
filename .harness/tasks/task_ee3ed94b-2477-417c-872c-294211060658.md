## 7. Risks & Assumptions

- **RISK-001**: Package location in Automated Harness may differ from the assumed `packages/<runner-package>` pattern. Mitigation: TASK-001 requires discovery before file creation.
- **RISK-002**: Windows shell quoting may break commands with spaces in paths. Mitigation: add Windows-path fixture tests and use explicit cwd/project path handling.
- **RISK-003**: Running full local gates may be slow. Mitigation: initial manifests keep `local` fast and reserve smoke/manual checks for `nightly` or `release`.
- **RISK-004**: Manual smoke commands could accidentally run in CI. Mitigation: schema supports `manual` and `manualOptIn`; runner excludes them unless `--include-manual` is passed.
- **RISK-005**: Logs may grow too large. Mitigation: implement `MAX_LOG_BYTES` and summary truncation metadata.
- **RISK-006**: CI parity may weaken existing JasonShell Windows CI if replaced incorrectly. Mitigation: only align gate names; do not remove existing checks unless equivalent manifest execution is verified.
