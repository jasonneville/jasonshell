Current baseline reference — what these improve
Enter opens

Current centered header: a compact field, conditional clear button, and an adjacent Enter hint. This reference is an excerpt, not a live product rendering.

Grounded in the shell. Base-dark colors, Open Sans / Segoe UI font stack, .28rem field radius, .56rem panel radius, .95rem query text, and layered controls come from src/app.css and SearchPanelSurface.css. Open Sans is used if installed; otherwise the product’s system fallback. No remote assets.

Scale. Product centered panel defaults to 720 × 560px (resizable, minimum width 420px). Preview caps at 720px; height is condensed for comparison. The 360px layout is a review adaptation, not a claim about native shell sizing.

Boundaries. Source filtering, query tokens, source menus, command-only mode and provider visibility are speculative. Apps, windows, settings, folders, saved commands and optional Everything results are existing search sources. Every match and provider state here is a fixed local example, not a search result from your computer. No IPC, network, persistence, or execution.

Try a field, change a scope, or press Enter. Only the mockup responds.
