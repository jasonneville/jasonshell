01 / Refined original

Closest to current

Adjoining square tiles, no gutters, and the familiar 2px left active marker. A slightly clearer active fill and quieter dividers are the only visual polish.

Pros: Lowest visual migration cost. Existing density, left-edge active cue, golden badge, and attention strip remain recognizable.

Trade-off: The continuous wall of filled tiles still feels broad when many windows are open.

02 / Soft inset rail

Recommended

Small tile gutters and a quiet beveled background break up the sprawl. A 3px inset and restrained corners make each task legible without turning the bar into a dock.

Pros: Less visual sprawl, clearer active task, and the same positions. The inset highlight adds finish without blur, glow, or a new visual language.

Trade-off: A few extra vertical pixels and gutters reduce available task space slightly.

03 / Underline rhythm

Lightest chrome

Remove idle tile fills and most dividers. Thin bottom rules establish a rhythm; the active window gets a brighter, thicker underline and a faint fill.

Pros: Calmest desktop edge. Titles and icons do the work rather than large blocks of background; a short rule also distinguishes the minimized task.

Trade-off: Task boundaries are less explicit. The active indicator moves from the left edge to the bottom.

04 / Hairline cells

Sharper structure

Keep the squared, adjoining geometry but replace raised fills with thin outlined cells. Slightly stronger utility endcaps anchor the rail; the active cell alone earns a bright outline.

Pros: Crisp boundaries with less filled area. Keeps the left active marker and uses a dashed lower edge as an additional minimized cue.

Trade-off: More linework than option 03. A large number of tasks can still read as a grid.

05 / Shallow tabs

Connected active state

Very shallow tabs meet a continuous bottom sill. The active task merges with that sill, while only the upper corners soften. Everything stays edge-attached and left-aligned.

Pros: A more deliberate silhouette without moving anything. The connected active tab creates a stronger structural cue than color alone.

Trade-off: Slightly more stylized. The active marker moves to the top and shares that edge with attention on other tasks.

Start with 02. Keep 01 as the conservative fallback.

Soft inset rail offers the best small refresh: enough separation to stop the tiles reading as one long slab, but no new placement, giant icons, or floating dock. Preserve the existing left active marker, grouped count, and attention edge. These are visual directions only—not implementation commitments or verified native sizing.
