Saved commands deserve a place that feels deliberate: easy to find, clear to configure, calm to watch.

Design intention

Show the meaning before the mechanics.

“Recipe” is proposed presentation language, not a new saved-command type.

Strength. Approachable configuration with strong reading order; native disclosures tuck away occasional fields.

Tradeoff. More vertical travel. Less efficient for frequent switching or watching long transcripts.

Recommended starting point

01, with a little 04.

Use the atelier as the low-disruption candidate. Its structure respects the current saved-list mental model. Borrow the ledger’s readable run summaries and generous output treatment. For a genuinely different challenger, test the focus room—not a recolored split pane. Choose only after observing command count, editing frequency and time spent reading transcripts; those usage facts were not established by this research.

State and safety notes / what a future implementation must preserve

Existing run history carries runId, processId, exitCode, stdout, stderr, running state and transcript records. A real implementation must preserve their identity and truthful outcome—not substitute decorative progress indicators.

  • Empty: “No quick commands saved.” First use should not imply a prepopulated command library.
  • Loading: “Loading commands…” and “Loading output…” remain visible, not disguised as empty results.
  • Errors: configuration validation and panel/input failures need explicit messages.
  • Running / stopping: preserve guarded Run/Stop state and prevent conflicting structural actions. This study shows no live execution.
  • Input required: pending requests need a labelled input area. Secret input remains masked and redacted in transcripts; never bake secrets into saved arguments or command lines.
  • Artifacts: an optional folder reference, not proof that a build created files.
  • Proposals: notebook terminology, card inspector, history-first emphasis, blueprint, centered stage and table expansion are design directions, not shipped capabilities. No search, grouping, scheduling or automation is claimed.
