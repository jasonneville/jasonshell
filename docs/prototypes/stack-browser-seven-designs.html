JasonShell is a Windows shell prototype built with Tauri 2, Svelte 5, TypeScript, Rust, and Win32.

How to choose a direction

For fast file managementStart with Precision. Borrow Reading room’s hierarchy only if the extra row height earns its space.
For browsing and understandingPathway preserves location; Side by side preserves content context. Pick which uncertainty matters more.
For a particular rhythmCollections favors recognition. Workbench favors repositories. Folder pocket favors brief, anchored visits.
Shared implementation guardrails

Keep keyboard selection, clear focus, accessible icon labels, folder-first sorting, metadata indicators, and truthful operation feedback. Loading must not look like an empty directory; partial listings and failed operations must remain explicit. No fake success state or decorative Git counters.

Comparison discipline

All seven use the same twelve entries and selected file. Details layouts show all four baseline columns; compressed layouts deliberately trade persistent metadata for space. Local modified dates are abbreviated visually, with full timestamps in each entry’s accessible label or tooltip.
