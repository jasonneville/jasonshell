Precision is the invariant.

File-first details, folders first, quiet outline icons, a thin selected-row rail, clear breadcrumbs, and inline status after Pin and before Search. Name, Type, Size, and Modified remain present in all seven. No card grids, full IDE, command dashboard, or oversized previews.

The shell provides the visual grammar.

Surfaces, text colors, borders, small radii, and compact spacing are grounded in src/app.css base-dark tokens. Olive is the proposed personal accent carried from Precision, not a claimed shipped theme. This offline file uses the shell’s system-font fallback rather than loading its font assets.

Customize the browser, not the entire shell.

A sensible starting pointEssential is the closest next step. Add Repo lens when Git context matters, or Familiar paths when navigation repeats.
A preference, not a new productKeyboard compass and Personal ledger tune how information is scanned. Selection shelf and Action dock tune how the selected file is understood and acted on.
One cohesive familyDensity, columns, shortcut hints, rails, and action placement could be composable preferences. These seven show deliberate combinations, not seven competing codebases.

Proposal boundary and safety.

Favorites, presets, a persistent Git column, row-number hints, selection shelf, and action dock are design proposals. Git branch/status values and preference state are explicitly illustrative. Chrome is nonfunctional. A runtime design would still need truthful loading, empty, partial-read, error, disabled, and operation-progress states.
