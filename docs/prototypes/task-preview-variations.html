JasonShell / design study

Same preview. A little different.

Three small changes to the task preview chrome, alongside a current-inspired baseline. Same window, same thumbnail, same small squared corners.

Close controls are demo-only.
00

Baseline

Current-inspired. Raised dark surface, .28rem corners, .35rem inset, and a compact two-line title/process header. Not a runtime screenshot.

01

Quiet outline

Only the perimeter changes. Add a 1px outline at 14% opacity. Keep the title, process, spacing, shadow, and thumbnail exactly as in the baseline.

02

One-line header

A slightly shorter surface. Place the process beside the title; reduce the desktop header from 2.2rem to 1.65rem. Thumbnail dimensions stay unchanged.

03

A little breathing room

Gentler hierarchy. Increase the inset to .5rem and header to 2.6rem; separate the two text lines by .18rem and add a small app mark in the header.

Thumbnails are simulated VS Code content, not live captures. Native live previews use a separate DWM rectangle: these concepts keep all controls in the header, with no overlays or new native actions. System fonts keep this file fully offline.
