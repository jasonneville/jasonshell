## Agreed contracts and boundaries

- `start_stack_folder_watch({ path: string })` → `{ watchId: string, canonicalPath: string }`; native derives canonical folder/repository/actual external Git metadata roots. Renderer supplies no root authority.
- `stop_stack_folder_watch({ watchId: string })` → void; a stale stop cannot retire a newer subscription.
- Popup-targeted `stack-popup:folder-changed` → `{ watchId: string }`.
- Popup-targeted `stack-popup:folder-watch-error` → `{ watchId: string, message: string }`; native stops a failed OS subscription and emits a fixed path-free diagnostic. Startup failure rejects start IPC.
- Same-repository navigation reuses the existing recursive subscription, not a new ACK/summary scan per child folder. Initial registration and reopen ACK catchup close the subscription gap. Context verification before badges remains required.
- Visible-unfocused remains eligible; hidden/closed/unmounted retires ownership. Debounced external events trigger lightweight rows/summary refresh, never full-workbench enrichment or interval Git polling. Single-flight work retains one dirty followup; late tokens/ACKs/results are rejected.
